Import Schedule

A CSV file, one row per weekly class — any faculty member, mixed in one file.

Columns: Employee ID, Subject, Class/Section, Room, Day of Week (Monday–Saturday), Scheduled Start (HH:mm), Scheduled End (HH:mm), Valid From (YYYY-MM-DD), Valid Until (YYYY-MM-DD). A header row is optional. .

Rows that conflict or fail validation are skipped and listed below — the rest of the file still imports; the server enforces the same conflict/overlap rule as Add Class.
